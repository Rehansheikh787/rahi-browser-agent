Built on Five Core Architectural Pillars

A complete browser agent operating with determinism and defense-in-depth security.

👀

1. The Eyes (Observe)

Mozilla Readability article parsing strips noise, ads, and footers. Visual Drag-to-Crop screenshot analysis with high-DPI scaling allows targeted multimodal queries on complex charts and graphics.

🧠

2. The Brain (Reason)

Grounded Q&A refuses hallucinations when facts are absent. YouTube summarization automatically parses timestamps and video notes into deep clickable links. Bilingual support in English and Hinglish.

✋

3. The Hands (Act)

Scans visible interactive DOM and overlays isolated Shadow DOM numbered badges. Proposes sequential actions with Dry Run previews and synthetic typing compatible with React controlled inputs.

🛡️

4. Hardcoded Safety

ADR-003 Defense-in-Depth: Layer 1 Domain Firewall blocks financial and auth portals; Layer 2 Sentinel blocks passwords and OTPs; Layer 3 enforces secondary confirmation for consequential actions.

👤

5. The Memory

On-device Local Profile Memory stores applicant attributes without third-party tracking. One-Click Skills Hub (rahi-skills-v1) lets you run, create, export, and import customized prompt recipes.

⚡

Zero-Downtime Resilience

Built with exponential backoff and jitter for free-tier rate limits, plus transparent failover to Groq Llama 3.3 70B when Gemini quotas are exhausted.

🛡️ DEFENSE IN DEPTH (ADR-003)

Enterprise-Grade Browser Safety by Design

Unlike cloud browser scrapers that transmit credentials, Rahi executes locally with strict deterministic boundaries:

1

Domain Firewall

Automated agent actions are unconditionally terminated on banking portals, payment processors, and authentication gateways.

2

Sensitive Element Sentinel

Rahi strictly refuses to interact with password fields, OTP inputs, or credit card forms—even if requested by model output.

3

Consequential Action Consent

Actions that submit data, delete content, or complete orders require checking an explicit secondary confirmation checkbox.

Get Started in 3 Simple Steps

1

Clone & Load Unpacked

Clone the repository, open chrome://extensions, enable Developer Mode, and click Load unpacked.

2

Add Your API Key

Open Rahi from your Side Panel, navigate to Settings, and paste your free Google Gemini API key. Optionally add a Groq fallback key.

3

Start Browsing Safely

Summarize any page, ask grounded questions, test One-Click Skills, or let Rahi guide your navigation step-by-step.
